# cybersec-learning-log

Journal de mon apprentissage de la cybersécurité : ce que j'ai fait, ce que je prévois, et un glossaire en français des notions de base.

Je suis étudiant en prépa ingénieur informatique à l'Icam Strasbourg-Europe et je cherche une alternance en cybersécurité à partir de septembre 2027.

## Ce que j'ai fait

- [x] **Hack The Box** : tutoriel d'initiation complété et modules de base de la plateforme (offre gratuite), connexion régulière.
- [x] **Cyber Ninja CTF** (31/01/2025) : participation en solo, plusieurs épreuves de programmation résolues.
- [x] **Programmation** : Python, C++ et JavaScript en pratique personnelle (voir mes autres dépôts).

## Ce que je prévois

Cette liste est mon plan de travail, pas une liste de compétences acquises. Je coche au fur et à mesure.

- [ ] Linux et ligne de commande : permissions, processus, redirections, scripts shell.
- [ ] Réseau : modèle OSI, TCP/IP, DNS, HTTP(S), lecture de captures avec Wireshark.
- [ ] Parcours gratuit d'initiation sur TryHackMe.
- [ ] MOOC SecNumacadémie de l'ANSSI.
- [ ] Failles web courantes (OWASP Top 10), entraînement sur des applications faites pour ça comme OWASP Juice Shop, en local.
- [ ] Premières machines Hack The Box.
- [ ] Un nouveau CTF.
